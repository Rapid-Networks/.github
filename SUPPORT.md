# Getting Help

## Questions and how-tos

Check the repo's README and docs first, since most setup and usage questions are answered there.

If you're still stuck, reach out to dev@rapidnetworks.co.za.

## Bugs

If something isn't working as documented, open a bug report from the
**Issues** tab of the repo you're using. Please include steps to reproduce,
and remove tokens, passwords and customer data from any logs.

## Feature requests

Open a feature request from the **Issues** tab of the relevant repo,
describing the problem you're trying to solve.

## Security issues

Please don't open a public issue. See our
[security policy](SECURITY.md).

## Response times

We're a small team and respond on a best-effort basis, usually within 5 business days.
